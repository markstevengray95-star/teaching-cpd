# Revision library source texts

The three bundled literary texts are public-domain works supplied in the
Project Gutenberg plain-text format. The files retain the Project Gutenberg
header, footer, licence and source metadata.

- `macbeth.txt` — William Shakespeare, *Macbeth*, Project Gutenberg eBook
  1533: https://www.gutenberg.org/ebooks/1533
- `romeo-and-juliet.txt` — William Shakespeare, *Romeo and Juliet*, Project
  Gutenberg eBook 1513: https://www.gutenberg.org/ebooks/1513
- `a-christmas-carol.txt` — Charles Dickens, *A Christmas Carol in Prose*,
  Project Gutenberg eBook 46: https://www.gutenberg.org/ebooks/46

The underlying works are out of copyright in the UK because their authors
died more than 70 years ago. Project Gutenberg's distribution terms are
included in each file and must remain with redistributed copies.

`An Inspector Calls` is intentionally not bundled. J. B. Priestley died in
1984, so the play remains protected by UK copyright under the usual
life-plus-70-years rule. The revision area contains original summaries,
character profiles, themes and questions only.
