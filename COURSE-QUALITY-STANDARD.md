# CPD Course Quality Standard — Phase 1

Template version: **2026.1**

Phase 1 gives every course in the Teaching CPD catalogue one shared structural and quality baseline. Bespoke course content is preserved, but every course is now audited against the same framework and receives the same orientation, baseline and implementation close.

## Common learning journey

1. **Orient** — purpose, audience, outcomes and visual course map.
2. **Diagnose** — baseline reflection/check to activate prior knowledge.
3. **Learn** — substantive professional knowledge in manageable chunks.
4. **Explore** — models, examples, diagrams and non-examples.
5. **Practise** — realistic rehearsal of the professional skill.
6. **Decide** — scenario/case requiring professional judgement.
7. **Check** — knowledge checks and feedback on misconceptions.
8. **Implement** — one action, one measure and one review point.

## 100-point automated audit

Each live course is checked for:

- Purpose and intended audience
- Three to six distinct learning objectives
- Presentation journey map as the opening slide
- Early diagnostic/baseline activity
- Core knowledge depth
- Visual communication
- Practical rehearsal
- Scenario/case-study application
- Knowledge checks with feedback
- Reflection and implementation planning
- Balanced presentation formats

Scores are grouped as:

- **Excellent:** 90–100%
- **Secure:** 78–89%
- **Developing:** 62–77%
- **Priority:** below 62%

The automated score is a structural/content-depth diagnostic, not a substitute for human accuracy, safeguarding, accessibility or evidence review. Those remain part of the school quality-assurance workflow.

## Phase 1 rules

All courses must retain unique IDs, contain interactive learning, include visual explanation and open with a presentation journey map. The Phase 1 framework additionally requires core purpose/audience information, a minimum of three distinct objectives, meaningful practice and an implementation/reflection close.

The existing bespoke quality checks for earlier course batches remain in place as regression protection. Phase 1 sits above them as the single catalogue-wide standard for current and future courses.

## Dashboard

The live automated audit is available at `/course-audit`. Courses are sorted from lowest score upward so Phase 2 can deepen the weakest content systematically rather than improving courses at random.
